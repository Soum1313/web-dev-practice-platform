# Available Dev Tasks

Total: **18 tasks** across two sections of the app.

## Day 1 Roadmap (12 tasks)

### HTML
1. `day1-01` — HTML Basics
   Practice editing basic HTML by making small text changes to the Student Portal page.
2. `day1-02` — HTML id & class Attributes
   Practice adding `id` and `class` attributes to existing HTML elements so they can be targeted individually or as a group.

### CSS
3. `day1-03` — CSS Basics
   Practice basic CSS properties by styling the Student Card page using `style.css`.
4. `day1-04` — CSS Selectors
   Practice the three most common CSS selector types: element, ID, and class selectors.

### HTML + CSS
5. `day1-11` — HTML + CSS Mini Project
   Combine everything learned about HTML attributes and CSS styling to turn a plain Student Profile Card into a properly styled card.

### JavaScript
6. `day1-05` — Select an Element
   Learn how to select an HTML element from JavaScript and store it in a variable.
7. `day1-06` — Change Text From JavaScript
   Learn how to select an element and change the text it displays using JavaScript.
8. `day1-07` — Responding to Click Events
   Learn how to respond to a button click using an event listener.
9. `day1-08` — Showing a Popup
   Learn how to show a popup message to the user in response to a button click.
10. `day1-09` — Reading Input & Conditions
    Learn how to read the value typed into an input field, and use `if` / `else` to make a decision based on it.
11. `day1-10` — Show / Hide Elements
    Learn how to hide and show an element using JavaScript by changing its `style.display` property.

### Full Project
12. `day1-12` — Full Project: Course Registration
    The final Day 1 exercise: combine HTML attributes, CSS styling, and JavaScript (selection, events, conditions, popups) into one working Course Registration form.

## Assessment Practice (6 tasks)

13. `task-01` — Interactive Counter
    Modify the existing counter application so + / - buttons work and the count can't go below zero.
14. `task-02` — Student Dashboard
    Add a missing HTML id, style it with CSS, and wire up a click interaction in JavaScript.
15. `task-03` — Course Registration
    Wire up a form so submitting it validates the fields and shows a success popup, without reloading the page.
16. `task-04` — Account Settings
    Implement working ON/OFF toggle switches — each toggle should update its visual state and label independently.
17. `task-05` — Student Registration Form
    Complete a form's validation logic: four validator functions plus a submit handler using existing helper functions.
18. `task-06` — Responsive Navbar
    Make a navbar collapse into a working hamburger menu on small screens, using a CSS media query and a JS click handler.
